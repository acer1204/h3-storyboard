System prompt

兩種分鏡模式各有獨立的一套 system prompt 庫；上面切換模式，這裡的清單就跟著換。 左邊勾選哪一組，產生時就用哪一組。編輯內容會自動保存到伺服器。

LoRA 觸發詞

存多組 LoRA 預設，左邊勾選哪一組，產生時就套用哪一組（勾「不套用」則完全不動）。兩種分鏡模式共用。 MAIN 會逐字放在 integrated_multimodal_description 最開頭、[Shot 1] 之前； SUB 依畫面行為自動觸發（模型放佔位符，程式換成精確 key；漏了由語意比對補入），也可勾「必出現」強制。 中文代號：在圖卡的「補充劇情」裡寫到這個詞（例如「她喝東西」命中「喝東西」），該 key 就自動視為必出現 —— 你的中文直接對到 LoRA，不靠模型翻譯。

刪除上傳圖片

「只從庫移除」不會動到任何歷史紀錄——每筆紀錄都保有自己的原圖，之後照樣能點開、重跑； 如果日後再上傳同一張圖，這些紀錄會自動重新掛回來。
